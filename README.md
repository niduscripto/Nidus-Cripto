# Nidus-Cripto

## Español

**Nidus-Cripto** es una aplicación móvil de billetera de criptomonedas desarrollada en **Kotlin** y **Jetpack Compose** para la plataforma Android. Está diseñada para ofrecer una gestión segura de llaves y transacciones locales, implementando una arquitectura robusta y soporte para redes de Bitcoin (tanto red principal como redes de prueba).

## 🚀 Características Principales

* **Gestión Segura de Llaves:** Arquitectura robusta para el manejo local de claves privadas y direcciones.
* **Soporte Multi-red:** Compatible con configuraciones para redes principales (mainnet) y de prueba (testnet) de Bitcoin.
* **Interfaz Moderna:** Diseñada completamente con **Jetpack Compose** para una experiencia de usuario fluida y adaptativa.
* **Seguridad y Privacidad:** 
  * Los datos sensibles y las direcciones de tarifas se manejan de forma aislada mediante variables inyectadas de manera segura (`BuildConfig` y `local.properties`), asegurando que ninguna información privada se filtre al control de versiones.

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Kotlin
* **Interfaz de Usuario:** Jetpack Compose
* **Arquitectura:** Patrones modernos de desarrollo en Android y componentes de ciclo de vida.
* **Control de Versiones:** Git y GitHub

## English

**Nidus-Cripto** is a mobile cryptocurrency wallet application developed in **Kotlin** and **Jetpack Compose** for the Android platform. It is designed to offer secure local key management and transaction handling, implementing a robust architecture with support for Bitcoin networks (both mainnet and testnet).

### 🚀 Key Features

* **Secure Key Management:** Robust architecture for local handling of private keys and addresses.
* **Multi-network Support:** Compatible with Bitcoin mainnet and testnet configurations.
* **Modern UI:** Built entirely with **Jetpack Compose** for a smooth and adaptive user experience.
* **Security & Privacy:** 
  * Sensitive data and fee addresses are isolated using securely injected variables (`BuildConfig` and `local.properties`), ensuring no private information is leaked to version control.

### 🛠️ Technologies Used

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Architecture:** Modern Android development patterns and lifecycle components.
* **Version Control:** Git and GitHub
